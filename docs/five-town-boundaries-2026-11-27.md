# 다섯 대상지의 세부구역 경계와 공동주택용지

2026.11.27 기준, 기존 대표 지번만 표시하던 세부구역 25곳에 사업구역 참고 경계를 추가했다. 340개 세부구역 중 경계가 있는 곳은 183곳에서 208곳, 핀만 있는 곳은 152곳에서 127곳으로 바뀌었다. 위치를 특정하지 못한 5곳은 별도로 남아 있다.

각 구역의 대표 지번점을 보존하고 도면에서 판독한 선, 공동주택용지, 출처 페이지를 별도로 기록했다. 아래 면적은 해당 문서의 기재값이고, 지도에서는 도면을 지적도 또는 서울시 공간자료와 맞춘 참고선을 표시한다. 실제 시행인가 도면과 관리계획 도면은 시점을 구별한다.
