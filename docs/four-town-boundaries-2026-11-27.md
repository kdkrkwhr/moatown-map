# 대표 핀만 있던 네 대상지의 세부구역 경계

2026.11.27 기준 고척동 241, 시흥5동 922-61, 마장동 457, 사당동 202-29의 세부구역 26곳을 검수해 26곳에 참고 경계를 추가했다. 전체 340개 세부구역 중 경계가 있는 곳은 157곳에서 183곳으로 늘었다. 대표 핀만 있는 곳은 178곳에서 152곳으로 줄었고, 이번 검수 대상의 기존 대표 지번과 좌표는 보존했다.

공식 고시의 구역별 번호·표·면적을 도면과 대조했다. 지도 라벨은 구역 안에 놓았다. 건물 노후도는 도면 안에 온전히 들어가는 기존 건물로 다시 계산했다.
