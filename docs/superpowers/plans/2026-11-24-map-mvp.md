# Moatown public map MVP implementation plan

1. Load the static manifest and its files relative to the deployment path. Test the actual snapshot counts, query validation, and coordinate order with `node --test tests/map.test.mjs`.
2. Build one selection and filter model for Leaflet and the accessible HTML list. Keep records visible if they lack map data. Show sourced values and label unknowns explicitly.
3. Mount separate reference town boundaries, reference zone boundaries, and representative pins. Keep those layers and list working if the external base tiles fail.
4. Verify interaction and loading with a browser rooted at a project subpath, mock tiles for repeated automation, and leave data files untouched.
