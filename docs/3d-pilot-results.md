### 신월동 정비 전 건물 보강

## 모바일 동작 확인

2026.11.25 신월동의 ‘계획자료 반영’ 예시에 27개 주거동 형태를 표시했다. A1은 시공사 선정안에 공개된 5동을 목표로 자동 배치했다. A3은 조합 배치도에 그려진 7개 주거동 형태를 개별 판독했다. A2의 7개와 A4의 8개는 세대수·구역 형태·가로 조건으로 생성한 예시다. 2023년 고시의 공원, 복지시설, 도로, 보행통로 10개를 대조했다. [A3 확대 보기](https://kdkrkwhr.github.io/moatown-map/?town=mt-202603-public-067&zone=mz-plan-584443-a3&view=3d&mode=after)

‘35m 간격 예시’에도 고시 기반시설을 반영했다. 배치 수는 A1·A2 각 2동, A3 4동, A4 3동으로 총 11동이다. 층당 4세대로 환산한 560세대와 입력자료상 계획 합계 1,839세대를 구분해 표시한다. [35m 간격 시뮬레이션](https://kdkrkwhr.github.io/moatown-map/?town=mt-202603-public-067&view=3d&mode=after&layout=spaced)

데스크톱 Chromium에서 세로 390×844 CSS 픽셀, DPR 2, 캐시 비활성화, 지연 80ms·다운로드 10Mbps로 설정해 로컬 정적 서버를 테스트했다. 지도 상세에서 ‘3D 보기’를 누른 시점부터 데이터 처리와 첫 렌더링을 끝내고 컨트롤을 활성화하기까지, 한 차례씩 측정한 값은 신월동 1.34초, 번동 1.02초, 면목동 1.64초였다. 실제 전화기의 GPU·네트워크에 따라 달라진다.

신월동 A2를 포함한 세 대상지에서 확대·회전 후 현재 건물과 사업 계획을 왕복하며 방향, 축척, 선택 구역이 유지되는지 확인했다. 뷰어의 지도 버튼과 브라우저 뒤로 가기로 진입 전 URL, 상세 탭, 시트 상태가 복원됐다. WebGL과 Canvas 대체 렌더러에서 건물·구역 선택을 확인했다.
